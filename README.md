# Cuvva Lite

### Cuvva Lite is a demo temporary car insurance platform

A user puts in their a car reg, driver information, then chooses how long they want cover for, receives a quote, purchases simulated policy and can then view or extend that policy.

It isn't real insurance and it doesn't take real payments.

### Tech Stack

Frontend: NextJs, Typescript & TailwindsCSS

Backend: Go, Vercel, Neon

Database: PostgreSQL

### Try the demo

1. Enter `FH18 UKU` as the vehicle registration.
2. Use any valid details, for example:
   - Age: 24
   - Licence held: 4 years
   - Penalty points: 0
